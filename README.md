# Shadow Hunt

A silhouette flashes for a fraction of a second. Four candidate shapes appear. Pick the one that matches.

## Play

- Watch the dark shape that briefly appears
- Tap the matching shape from the four below
- Each correct pick speeds the next reveal

## Build

```
flutter pub get
flutter run
flutter build apk --release
```
